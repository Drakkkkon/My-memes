# Мое_мемы

Сайт для поиска, редактирования и сохранения мемов. Версия **0.2.0 альфа**.

Сайт: https://drakkkkon.github.io/My-memes/

- **Мемы** — вкладки «Новые», «Классика», «Избранное». В «Новых» и «Классике» — подменю: знаменитости (Илон Маск, Киану Ривз, Дрейк, ДиКаприо, Дружко, Понасенков и др.) и категории (коты, собаки, работа, игры, кино, аниме, программисты…). Поиск по-русски и по-английски.
- **Бесконечная лента** — новые мемы подгружаются при листании и при просмотре картинок (листание пальцем влево/вправо). Всё пролистанное сохраняется в кеше устройства (списки — IndexedDB, картинки — service worker) и открывается без интернета.
- **Базы мемов** (⚙️ Настройки, можно выбрать несколько): Imgflip, Memegen, Reddit, Reddit RU (r/Pikabu, r/KafkaFPS, r/ANormalDayInRussia), Мемепедия (база русских мемов), Lemmy.
- **Редактор** — блоки текста (шрифт, размер, цвет, обводка, плашка, поворот), обрезка картинки, размер холста (по умолчанию 1:1, 1800×1800).
- **Сохранение** — в базу сайта (IndexedDB в браузере) и JPEG на телефон.
