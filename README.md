# Мое_мемы

Сайт для поиска, редактирования и сохранения мемов. Версия **0.3.0 альфа**.

Сайт: https://drakkkkon.github.io/My-memes/

- **Мемы** — вкладки «Новые», «Классика», «Избранное». В «Новых» и «Классике» — подменю: знаменитости (Илон Маск, Киану Ривз, Дрейк, ДиКаприо, Дружко, Понасенков и др.) и категории (коты, собаки, работа, игры, кино, аниме, программисты…). Поиск по-русски и по-английски.
- **Бесконечная лента** — новые мемы подгружаются при листании и при просмотре картинок (листание пальцем влево/вправо). Всё пролистанное сохраняется в кеше устройства (списки — IndexedDB, картинки — service worker) и открывается без интернета.
- **Базы мемов** (⚙️ Настройки, можно выбрать несколько): Imgflip, Memegen, Reddit, Reddit RU (r/Pikabu, r/KafkaFPS, r/ANormalDayInRussia), Мемепедия (база русских мемов), Lemmy.
- **Редактор** — блоки текста (шрифт, размер, цвет, обводка, плашка, поворот), обрезка картинки, размер холста (по умолчанию 1:1, 1800×1800).
- **Сохранение** — в базу сайта (IndexedDB в браузере) и JPEG на телефон.

## Приложение Android
Скачать: [Moe_memy_v0.3.0.apk](https://raw.githubusercontent.com/Drakkkkon/maymani/archives/memy/Moe_memy_v0.3.0.apk) (Android 8 и новее).

- Это оболочка вокруг сайта (папка `android/`): изменения сайта появляются в приложении сами, без нового APK.
- Сохранение JPEG в галерею (Pictures/Мое_мемы), «Поделиться», системные уведомления о свежих мемах и новой версии.
- Обновление APK: приложение читает `updates/memy.json` в репозитории maymani, скачивает файл из ветки `archives` (папка `memy/`), проверяет SHA-256 и предлагает установить.
- Новая версия APK: поднять `versionCode`/`versionName` в `android/AndroidManifest.xml`, собрать `android/build.sh` с тем же ключом, положить APK в `archives/memy/`, обновить `updates/memy.json`.
- Ключ подписи в репозиторий не класть. Без него обновление поверх установленного приложения невозможно.
